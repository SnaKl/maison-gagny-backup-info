Privacy Policy

Last updated: 26 October 2026

Maison Gagny Backup is a private application operated by and for a single user to back up that user's own home server.

Google data accessed

The application requests the drive.file scope. This permits access only to Google Drive files and folders created by the application.

How data is used

Backup data is encrypted locally before it is uploaded to the user's own Google Drive. Google Drive is used solely as off-site storage for these encrypted backup files.

Data sharing and collection

The application does not collect analytics, sell data, serve advertising, or share Google user data with third parties. OAuth credentials and tokens remain on the user's own server.

Retention and deletion

The user controls backup retention. The user can delete the backup folder from Google Drive and can revoke the application's access at any time from their Google Account security settings.

Contact

Questions can be submitted through the project's GitHub issue tracker.
